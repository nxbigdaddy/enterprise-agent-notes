# 08 · 功能补充清单

> 版本：v0.1（草稿）
> 本文回答一个问题：**在已明确的需求之外，还差哪些功能？**
> 标记：`P0` 必做（否则跑不起来） · `P1` 应该做（决定好不好用） · `P2` 可以做（决定能不能长大）

---

## 0. 已明确 vs 待补齐

| 已有规划 | 本文补充的重点 |
|---|---|
| AI API 统一管理 | 网关的**治理**能力（密级路由、脱敏、评测、成本） |
| 统一用户管理 | **数据权限**与**能力分级**的落地机制 |
| 三端互通 | **通知中心**、**跨端任务状态**、**冲突与降级** |
| 桌面端本机能力 | **本地插件体系**、**本地策略引擎**、**可撤销** |
| 邮件管理 | **待办抽取**、**跟进闭环**、**发信安全** |
| —— | **知识库、工作流、连接器、审计、可观测、管理后台、技能市场** |

> 一句话结论：你现在的清单是「**用户能用的功能**」，缺的是「**让这些功能在公司里活下来的功能**」。下面 D 组和 E 组最容易被忽略，但决定项目成败。

## H. 优先级汇总（一页版）

**P0 —— 没有它就不成立（约 25 项）**

> AI 网关（模型注册+路由+密钥+配额+成本+日志）、用户与组织同步、SSO、角色与能力、数据权限、RAG + 权限继承 + 引用、文档生成与解析、邮件读写与草稿、Agent 运行时、工具注册表、沙箱、人工确认、审计中心、DLP/脱敏、可观测性、配置中心、降级容错、管理后台（用户/模型/配额/审计）、通知中心、待办中心、三端基础互通。

**P1 —— 决定好不好用**

> 工作流引擎、连接器、日程会议、模板中心、统一搜索、OCR、批量与长任务、评测与门禁、反馈闭环、知识治理、设备管理、个人工作台、技能与连接器管理后台、灰度发布、数据保留。

**P2 —— 决定能不能长大**

> 技能市场、插件 SDK、多 Agent、Text2SQL、RPA、会议转写、A/B、开放平台、离线能力、信创适配。

## I. 如果只能补三件事，补这三件

1. **审计中心（D1）**——没有留痕，任何安全评审都过不了，桌面端和邮件功能直接卡死。
2. **知识库 + 权限继承（A1/A2）**——没有它，Agent 只能闲聊，无法回答公司内部问题；权限继承没做好，第一天就会出越权事故。
3. **工作流与定时（C5/C8）**——这是把「助手」变成「员工离不开的工具」的关键，也是最能体现节省时间的部分。

## J. 需要需求方补充的信息

1. 公司目前有哪些**内部系统**（OA/ERP/CRM/HR/工单/网盘/文档平台），各自有无 API？
2. 是否已有**统一身份认证**（AD/LDAP/CAS/OAuth）？企微是否为组织事实源？
3. 数据**密级制度**是否已存在？分几档？
4. 是否有**合规/等保**要求？审计日志保留多久？
5. 首批试点的**部门与 3 个标杆场景**是什么？
6. 可投入的**人力与预算**规模？是否有 GPU 资源？
7. 是否有**已有的 AI 工具**在用（避免重复建设，也便于整合）？

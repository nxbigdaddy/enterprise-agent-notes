# 03 · 统一 AI 能力网关

> 版本：v0.1（草稿） · 对应需求：「公司统一的 AI API 管理（使用外部 API 或内部的自建模型）」

## 1. 为什么需要它

如果只是把请求转发给模型厂商，那你得到的是**更高的账单**和**更差的可控性**。网关的价值在于它承担了公司级治理：

| 没有网关 | 有网关 |
|---|---|
| 每个系统各自申请 key，泄露无人知 | 密钥集中托管，可随时吊销、可轮换 |
| 用量是一笔糊涂账 | 按人/部门/应用可核算、可限额 |
| 敏感数据随手发给外部模型 | 按数据密级自动路由到内网模型 |
| 换模型要改所有业务代码 | 改路由配置即可 |
| 出问题只能看到「模型返回错了」 | 全链路 trace，可回放 |

**一句话**：网关是 AI 能力进入公司的**唯一收费口 + 唯一审计口 + 唯一合规口**。

## 2. 能力范围

### 2.1 模型类型支持

| 类型 | 用途 | 备注 |
|---|---|---|
| Chat / 推理 | 对话、写作、分析 | 主力 |
| Embedding | 知识库向量化 | 建议自建，量大且便宜 |
| Rerank | 检索结果重排 | 显著提升 RAG 质量 |
| OCR / 文档解析 | 扫描件、图片 | 可用外部服务或本地模型 |
| ASR / TTS | 会议录音转写、语音播报 | P2 |
| 图像理解 / 生成 | 图表理解、配图 | P2 |
| 代码执行 | 数据分析沙箱 | 必须隔离 |

### 2.2 模型来源

| 来源 | 典型 | 接入方式 |
|---|---|---|
| 外部商用 API | OpenAI、Claude、Gemini、通义/文心/豆包/DeepSeek | OpenAI 兼容协议适配器 |
| 外部云私有实例 | 云厂商独享部署 | 同上，标记为「可信通道」 |
| **内部自建模型** | vLLM / Ollama / TGI 部署的开源模型 | OpenAI 兼容端点 |
| 微调模型 | 基于内部语料的 LoRA | 独立版本号管理 |

**重要**：自建模型不一定要「全能」。最实用的组合是——**自建小模型做 embedding / rerank / 分类 / 脱敏检测，外部强模型做复杂推理与写作**。

## 3. 核心功能

### 3.1 统一协议

对外暴露 **OpenAI 兼容协议**（`/v1/chat/completions`、`/v1/embeddings`），理由：

- 生态最广，业务侧 SDK 几乎零改造；
- 便于日后替换后端模型；
- 自建模型（vLLM/Ollama）原生兼容。

同时提供一层**内部增强协议**，支持流式、工具调用、结构化输出、多模态、引用标注。

### 3.2 路由策略

请求进入后按以下顺序决策：

```
1. 数据密级判定   → 绝密/机密 ⇒ 仅内网模型；公开/内部 ⇒ 可走外部
2. 场景策略       → 场景(如「合同审阅」)可强制指定模型
3. 能力要求       → 需视觉/长上下文/工具调用 ⇒ 过滤掉不支持的模型
4. 成本与配额     → 高成本模型需额度或审批
5. 可用性与负载   → 健康检查 + 熔断，自动切换备选
6. A/B 与灰度     → 按用户/部门比例分流
```

路由结果必须**记录到审计日志**（用了哪个模型、为什么）。

### 3.3 配额与限流

| 维度 | 举例 |
|---|---|
| 用户级 | 普通员工 50 万 token/月 |
| 部门级 | 部门总额池，按人分配 |
| 应用/技能级 | 某批量任务每日最多 1000 次调用 |
| 模型级 | 贵模型每天限 200 次 |
| 时段级 | 工作时间优先，夜间批处理让路 |

超限行为：**排队 → 降级到便宜模型 → 阻断并提示**（不要直接报错）。

### 3.4 成本核算

- 每次调用记录：模型、输入/输出 token、单价、费用、调用方、场景、trace_id
- 输出：个人 / 部门 / 场景 / 模型 多维成本报表
- 支持预算告警（用到 80% 通知管理员）与硬上限
- 自建模型按 GPU 时长折算成本，避免「自建=免费」的错觉

### 3.5 数据安全与脱敏

| 能力 | 说明 |
|---|---|
| 密级路由 | 见 3.2 |
| 敏感信息识别 | 身份证、手机号、银行卡、工资、客户名单、合同金额 |
| 脱敏策略 | 出网前掩码 / 占位符替换 / 直接阻断 |
| 反向还原 | 模型返回后再把占位符还原为真值（仅在内网侧进行） |
| 日志脱敏 | 审计日志存储前脱敏，避免日志成为新的泄露面 |
| 提示注入防护 | 检测文档中夹带的指令，隔离不可信内容 |

### 3.6 缓存

- **精确缓存**：同 prompt + 同参数 → 直接返回（问答类命中率可达 20%+）
- **语义缓存**：相似问题命中（需谨慎，容易给错答案，建议仅用于 FAQ 类）
- 缓存的 key 必须包含**权限上下文**，否则会串数据

### 3.7 Prompt / Agent 配置中心

| 项 | 说明 |
|---|---|
| Prompt 版本管理 | 每个 Prompt 有版本、变更记录、负责人 |
| 灰度发布 | 先 5% 用户，观察质量与成本再全量 |
| 变量与模板 | 支持 ${user.name} 等上下文变量 |
| 联调与预览 | 管理员可直接试跑对比 |
| 一键回滚 | 质量下降立刻回退 |

### 3.8 评测与质量门禁

- 用例集：每个场景维护一组「输入 → 期望要点」的用例
- 回归：换模型 / 改 Prompt 前后自动跑一遍，生成对比报告
- 指标：准确率、引用正确率、幻觉率、拒答率、平均延迟、平均成本
- 门禁：核心场景指标下降超过阈值则阻止上线

### 3.9 可观测性

每次调用记录：`trace_id、用户、部门、场景、模型、路由原因、耗时、token、费用、是否命中缓存、是否降级、错误码`

支持：按用户/场景检索、失败重放（用相同输入复现）、慢请求分析。

## 4. 关键接口（示意）

```
POST /v1/chat/completions        # OpenAI 兼容，业务方直接调用
POST /internal/ai/invoke         # 内部增强协议：带场景、密级、引用要求

GET  /admin/models               # 模型列表与健康状态
POST /admin/models               # 注册模型（外部/自建）
PUT  /admin/routes               # 编辑路由策略
GET  /admin/usage?dept=&range=   # 用量与成本查询
PUT  /admin/quota                # 配额配置
GET  /admin/prompts/{id}/versions
POST /admin/eval/run             # 触发评测
```

## 5. 数据模型（核心表）

| 表 | 关键字段 |
|---|---|
| `model_provider` | id, name, type(external/internal), endpoint, credential_ref, health, enabled |
| `model` | id, provider_id, name, capabilities, context_window, price_in, price_out, data_level_allowed |
| `route_policy` | id, scene, data_level, prefer_model, fallback_chain, priority |
| `quota` | id, scope(user/dept/app), target_id, period, limit, used |
| `ai_call_log` | trace_id, user_id, dept_id, scene, model_id, tokens_in/out, cost, latency, cached, degraded, created_at |
| `prompt_template` | id, scene, version, content, status, owner |
| `eval_case` / `eval_run` | scene, input, expected, score, model, prompt_version |

## 6. 落地顺序建议

| 阶段 | 内容 |
|---|---|
| P0 | 模型注册 + OpenAI 兼容代理 + 密钥托管 + 调用日志 + 基础限流 |
| P0 | 按场景路由 + 外部/自建双通道 + 成本记录 |
| P1 | 密级路由 + 脱敏 + 缓存 + Prompt 版本管理 |
| P1 | 配额体系 + 成本报表 + 评测回归 |
| P2 | 语义缓存、A/B、智能路由（按难度自动选模型省成本） |

## 7. 常见坑

1. **「自建模型免费」的错觉**——GPU 折旧 + 运维人力要算进去，否则预算会失控。
2. **忽略 embedding 成本**——知识库重建一次可能比一个月的对话调用还贵。
3. **脱敏后无法还原**——模型返回的占位符要能映射回真值，且映射表只在内网。
4. **缓存 key 不含权限**——最隐蔽的串数据 bug。
5. **没有降级链**——外部 API 一抖，全公司助手集体不可用。
